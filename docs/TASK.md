ТЕСТОВОЕ ЗАДАНИЕ: AI-АССИСТЕНТ ДЛЯ IPHONE

Сделайте небольшое приложение — AI-чат в духе ChatGPT. Пишите его с помощью любых AI-инструментов: Claude Code, Codex, Cursor, ChatGPT — на ваш выбор, платных или бесплатных. Нам важно увидеть, как вы работаете с LLM и какое приложение у вас получается.


ЧТО СДЕЛАТЬ

• Чат с AI: ответ появляется по мере генерации, есть кнопка «Стоп».
• Несколько чатов; история сохраняется после перезапуска.
• Понятные состояния: загрузка, ошибка (нет сети, кончился лимит API) с кнопкой «Повторить», пустой экран.
• Аккуратный интерфейс в духе iOS, светлая и тёмная тема.
• По желанию: фото во вложении, версия для Mac, офлайн-режим на Apple Foundation Models для iOS 26+.


ТРЕБОВАНИЯ К ПРОЕКТУ

• Минимальная версия iOS — 18: приложение должно работать и на iOS 18, и на последней iOS.
• Проект на XcodeGen (project.yml). В корне — файл Build.command: двойной клик в Finder сам запускает xcodegen generate и собирает проект под симулятор, без ручных команд в терминале.
• Зависимости — только через Swift Package Manager, без CocoaPods.


AI ВНУТРИ ПРИЛОЖЕНИЯ

Любой облачный API на ваш выбор, подойдут бесплатные: OpenRouter (бесплатные модели), Groq, Gemini API или Cloudflare Workers AI. Ключ положите прямо в проект в обфусцированном виде, не открытым текстом. Приложение должно запускаться сразу после сборки, без настроек. Проверьте, что у ключа останется бесплатный лимит на нашу проверку.


СРОК

Один рабочий день. Засеките, сколько часов ушло на самом деле: скорость нам тоже важна.


ЧТО ПРИСЛАТЬ

Архив (zip) всей папки проекта вместе с папкой .git — файлом или ссылкой на облако. В архиве:

1. Проект, который собирается двойным кликом по Build.command. Коммитьте по ходу работы, а не одним коммитом в конце.

2. Документацию, по которой вы вели AI: описание задачи, план, правила для агента (CLAUDE.md, AGENTS.md и т. п.) — в том виде, в каком реально её использовали. Описание и план — в папке docs/, файлы правил — там, где их читал агент.

3. Папку ai-logs/ с историей работы с AI. Claude Code и Codex сохраняют логи сами: Claude Code — папка вашего проекта в ~/.claude/projects/, Codex — файлы за дни работы в ~/.codex/sessions/. Из Cursor и чатов в браузере — экспорт или ссылки на чаты. Уберите из логов ключи и личные данные.

4. README по шаблону:
   — Время: сколько часов ушло.
   — Инструменты: какими AI-инструментами и моделями пользовались.
   — AI в приложении: какой сервис и какая модель.
   — Сделано: что работает.
   — Не сделано и известные баги.
   — Как проверяли, что всё работает.
